# E-Commerce Sales Analytics Dashboard

## Project Overview
This project is an interactive Power BI dashboard developed to analyze e-commerce sales performance. It provides insights into revenue, orders, quantity sold, product categories, payment methods, delivery status, customer locations, and sales trends.

## Objectives
- Analyze total sales and revenue trends.
- Track total orders and quantity sold.
- Identify top-performing product categories and products.
- Analyze sales by payment method.
- Monitor delivery status and customer reviews.
- Analyze sales performance across different states.
- Provide interactive filters for better data analysis.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Microsoft Excel / CSV

## Key Insights
The dashboard includes KPIs and interactive visualizations for Total Sales, Total Orders, Total Quantity, Average Order Value, monthly sales trends, product category performance, payment methods, delivery status, and top products.

## Dashboard
The dashboard provides an interactive and user-friendly view of e-commerce sales data to support data analysis and decision-making.
